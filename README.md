Marketing landing page for IAM BioWell, a concierge wellness and longevity brand offering in-home consultations, lab draws, health scans and customized action plans. Built with Next.js (App Router), Tailwind CSS and Framer Motion. Testimonials and people shown are sample content.

## Getting started

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
npm run start
npm run lint
```

## Structure

```
src/app/          layout, global styles, home page
src/components/   page sections (Hero, Services, SocialProof, Footer, ...)
src/components/ui/ shared animation helpers
public/           images, hero videos, logo
```
